# 业务行为与重构验收

## 行为基线

基线提交：`86ecfebc907f887bb2769c380b14bffe4298b263`。技术栈为 React 18、Tauri 1、Rust，运行平台为 Windows。

| 业务     | 契约                                                                       |
| -------- | -------------------------------------------------------------------------- |
| 订阅     | remote/local 可激活；merge/script 是增强项；固定全局脚本先于用户增强链执行 |
| 配置     | 已提交快照是读取来源；候选状态属于单次操作；失败不得发布候选状态           |
| 端口     | 一次保存接收全部端口，内核与系统代理使用同一个目标配置                     |
| 节点选择 | 核心选择和订阅中的选择记录由同一操作协调；订阅切换完成后恢复有效选择       |
| 自动更新 | 新建、修改、删除订阅后的调度任务集合与已提交订阅一致                       |
| 实时数据 | 旧连接、旧请求和旧测试轮次不能覆盖当前代次；断线轮询在 WS 恢复后结束       |
| 窗口     | 关闭隐藏；显式显示优先于旧隐藏请求；退出后不接受恢复任务                   |
| 持久化   | 保留现有 YAML 字段和配置目录；跨文件变更具有恢复记录                       |

## 回归场景

- 候选配置的并发读取、并发写入、校验拒绝、外部执行失败、保存失败、补偿失败。
- 删除当前订阅、删除最后一个普通订阅、无效排序 ID、增强链引用清理。
- 系统代理开启时修改端口；端口边界和重复监听端口校验。
- 新建与删除带自动更新周期的订阅。
- 快速切换订阅、节点恢复失败、控制器 HTTP 拒绝。
- WS 恢复期间仍有 HTTP 请求在执行；隐藏、卸载、重连与旧请求完成交错。
- 控制器初始化失败、并发初始化与旧初始化晚完成。
- 窗口显示、隐藏、重建、正常退出与 Watchdog 恢复。

## 验证边界

纯业务与失败注入测试使用内存替身或工作区临时目录，不读写用户运行实例。测试订阅属于集成验证输入，不进入仓库、日志正文或测试快照。真实 Windows 副作用验收需记录测试实例、前后状态与恢复结果。
