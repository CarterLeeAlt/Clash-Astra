# 当前版本清理与窗口尺寸验证记录

适用范围：2026-10-31，`1.8.2`，基于提交 `aac01d16746e1842618277a93006aab1e9c672a5` 的工作树修改。本文只记录本次验收证据；当前规则见 [业务流程与状态归属](../architecture/application-flow.md)。

## 交付范围

- 默认和最小内容区均为 `1100×700` 逻辑像素；创建、状态保存及恢复共用尺寸约束，保留日常窗口记忆，不引入旧版本尺寸特例。
- 只支持当前 Mihomo 稳定版与 Alpha。移除旧订阅索引补 UID、默认名称改写、全局脚本身份迁移、旧内核内建转换及整条增强开关设置链。
- 当前订阅索引模板直接包含全局脚本；加载和提交校验完整性及引用。无效索引先备份再使用当前默认结构，备份失败阻止覆盖；这属于损坏数据保护，不是旧结构迁移。
- 旧 `script` 代理模式及字符串形式的 Hysteria ALPN 明确失败，不自动转换。用户显式配置的全局脚本和增强链仍保留。
- 测试站点由后端首次模板初始化，前端只添加图标和只读标记，移除按名称／URL 识别旧项、地址替换、补项和迁移回写。
- 清理无入口的 `ignore-case.ts`、无调用的前端 HTTP 测速入口及 IPC 包装、闲置缓存刷新函数、运行时配置键收集链、未使用的调度 Cron 分支、未引用类型和多余导出。仅测试使用的调度查询方法使用 `cfg(test)`；实际使用的系统代理自愈、共享服务／Watchdog 协议、Windows 路径处理和 WebView2 平台适配保留。
- 构建资源准备只处理当前服务文件；旧资源名拒绝检查保留，不能把防止旧产物混入发布包的校验当作兼容删除。

## 真实内核验证边界

授权测试订阅通过代理下载时，普通 User-Agent 和应用默认 `clash-astra/v1.8.2` 两次请求均未通过 YAML 映射校验；按应用默认 User-Agent 重试的响应体实测为空。没有转换响应，也没有把该远程订阅记作通过。

通过的隔离测试使用明确构造的当前格式夹具，含一个只指向本机端口的 SOCKS 节点；验证范围为配置编译与校验、控制器就绪、代理表读取、模式修改、错误鉴权拒绝、无效配置拒绝后回滚、内核接受后提交失败回滚、正常事务提交。该测试不验证远程订阅、远程节点连通性或吞吐。

Watchdog 测试脚本的默认路径指向带 target triple 的构建目录，本机默认构建未生成该路径。使用脚本已有的 `-WatchdogPath` 参数指向本次构建的实际输出，不更改应用行为或为旧版本添加路径回退。
