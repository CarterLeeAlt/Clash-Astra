# 窗口尺寸调整与便携包验证

适用范围：2026-10-31，当前 `1.8.2` 工作树，将默认和最小窗口内容区尺寸统一为 `1150×720` 逻辑像素。本记录保留验证证据，当前行为以 [业务流程](../architecture/application-flow.md) 和源码为准。

## 调整范围

- `src-tauri/src/domain/window_geometry.rs` 集中维护默认尺寸、最小尺寸、历史几何校验和保存门槛。
- `src-tauri/src/window/create.rs` 使用共享常量设置默认内容区和最小内容区；普通创建与恢复回退均使用同一默认值。
- `src-tauri/src/window/persist.rs` 使用同一校验规则保存普通窗口几何数据。
- 默认与最小尺寸均为 `1150×720`；尺寸不包含系统标题栏和边框，物理像素随 Windows DPI 换算。
- 符合新下限的较大历史尺寸与最大化恢复行为保留；低于下限的历史记录不恢复，回退为默认尺寸并居中。
- 不改运行中的窗口、不手工编辑用户配置、不修改系统缩放，保留此前图标修复。

## 验证边界

没有启动完整 GUI 做桌面拖动缩放或人工点击验收。自动化验证覆盖共享规则、建窗参数接入、保存门槛及编译；不把源码与边界测试表述为正在运行的窗口已经变化。

切换到新包时先从托盘退出旧实例，完整更新程序文件并保留原 `.config`。已有有效历史尺寸可能仍比默认值大，这是恢复行为，不表示新默认值失效。
