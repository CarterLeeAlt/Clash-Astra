## 源头修复

- 原生 Mihomo 节点在 Sublink 输出端保留原字段，不经过有损中间节点模型；不在客户端补旧协议转换层。
- Hysteria 1 YAML 保留协议身份；Hysteria 1 URI 转换明确拒绝，不伪装成 Hysteria2。
- 修复 VMess ALPN/指纹、VLESS HTTP/H2、常用 XHTTP URI host/path/mode/extra，以及显式 TLS 布尔值语义。复杂 XHTTP extra 无明确映射时拒绝而非猜测；原生 YAML 保留。
- 空代理源及失败上游明确失败，不生成正常外观的 DIRECT-only 订阅。Provider 下载 UA 与初次获取保持一致，版本/契约随配置和响应头声明。
- Astra 区分下载结构校验、最终配置校验、内核加载和集合就绪；非激活订阅不显示已验证就绪。脚本异常阻止候选提交，原生校验合并 stdout/stderr，保留事务补偿。
- 应用只覆盖明确归属的本机管理字段，保留订阅 DNS 和节点参数，不将全局 ipv6 再写入 dns.ipv6。
- 删除 Alpha 和自升级整条调用链，包括服务允许项、防火墙列表和打包引用。固定资产及已有文件在准备、构建、测试、打包和启动前校验；不重新签署上游内核。
- 服务资源按本次构建的内容同步，防止把仍支持旧路径的缓存服务二进制混入新包。

## 真实订阅验收

授权短链实际为 **302 → 200**，最终响应 `text/yaml; charset=utf-8`，本次线上响应约 13.8 KB，包含一个 VLESS/XHTTP 节点。线上响应未声明 Mihomo 版本/契约，节点只有 `network: xhttp`、缺少 `xhttp-opts`；不能据此认定线上已经匹配当前契约。此前未跟随重定向的 curl 空文件不构成“订阅返回空配置”的证据。

本地修复版用同一短链解析出的生成输入及参数重新生成，保留 XHTTP host/path/mode 与 `xPaddingBytes`，声明目标版本/契约。该配置经过 Astra 的实际下载解析及最终编译，在独立端口、目录和锁定内核中加载，未删除 DNS、分组、规则或 33 个规则集合；集合就绪检查通过。

在这个独立内核中针对真实节点调用延迟 API，不修改运行实例的节点选择：

| 目标                | 结果         |
| ------------------- | ------------ |
| Google generate_204 | 成功，247 ms |
| GitHub              | 成功，290 ms |

同时完整后端回归为 79 通过、0 忽略；随后增加集合空内容拒绝测试，最终受控完整回归为 80 通过。以上是不同批次，不将其计数混合，也不将代理首字节探测与真实节点 HTTP 测试混为一谈。

线上 Sublink 未部署，原运行实例未导入本地配置。通过的是本地修复版和指定内核的组合；不能把结果外推为线上已修好、所有远程节点可用或所有协议完成真实服务端握手。
